# 管理后台术语

| 中文 | English | 使用位置 |
| --- | --- | --- |
| 超级管理员 / 管理员 / 用户 | Root / Admin / User | 系统角色 |
| 个人访问令牌 | Personal access token | 限定账户与权限范围的 API 凭据 |
| 通行密钥 | Passkey | WebAuthn 注册与登录 |
| 审计日志 | Audit logs | 管理员查阅的操作记录 |
| 待处理 / 处理中 / 已完成 | Awaiting processing / In progress / Completed | 工单状态 |
| 待认领 | Unassigned | 处理人筛选 |
| 请求体缓存 | Request body cache | 临时文件与磁盘运维 |

七种前端语言以同一组英文源键维护。上游独立协议工具包沿用各自接口中的术语。
