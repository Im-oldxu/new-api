## [Unreleased]

## [1.0.0] - 2026-11-22

### 新增功能

- 提供包含用户、账号安全、权限、审计、设置与运维的通用管理后台。新安装可以独立于历史 AI 网关表运行。
- 提供可移除的工单示例，覆盖附件、办理记录、角色数据范围、概览统计以及可显式导入和清理的演示数据。

### 优化改进

- 概览聚焦业务统计，工单状态采用浅色和深色主题配色，管理员可切换个人和全站范围。
- 支持按安装实例设置品牌、内容和导航；维护页使用运行版本，可按部署选择公开发布仓库。
- README 提供 Linux Bash 的源码安装、SQLite 启停、Docker 配置、模板复用和版本发布步骤，并附有实际界面截图。

### Bug 修复

- 错误页的反馈按钮现在打开本模板的 GitHub Issues。
- 修正退役接口的前端重定向、旧网关配置写入和部分设置启停、密钥回显及保存顺序问题。
- 修复长工单标题在窄屏下撑宽详情的问题，概览、列表及详情统一状态文案。

### 兼容与升级

- 引用宿主 Go 包的扩展请将导入前缀更新为 `github.com/Im-oldxu/new-api`。自定义构建脚本写入版本时使用 `github.com/Im-oldxu/new-api/common.Version`。
- 升级保留原网关历史表、字段和配置。新安装只初始化底座和已安装示例所需结构。
